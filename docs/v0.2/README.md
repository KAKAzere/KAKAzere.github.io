# Project Polaris — v0.2 Structural Rebuild

> A new structure. A new direction.

Project Polaris v0.2 marks the first major structural rebuild of the project.

The goal of this version was not to finish the visual design, but to rebuild the foundation of the cinematic experience and establish a clearer direction for future development.

## Version

**v0.2 — Structural Rebuild**

## What Changed

- Rebuilt the main cinematic scene structure
- Introduced a fixed navigation system
- Established a dedicated central visual stage
- Separated navigation, subject, and primary content
- Reduced the visual dominance of scene nodes
- Added a new 3D scene foundation
- Prepared the layout for future 3D subjects, images, and media
- Refined the overall visual hierarchy

## Design Direction

The new structure follows one core principle:

> Keep navigation quiet.  
> Keep the subject clear.  
> Let the scene become the experience.

Navigation should help users understand where they are without becoming the focus of the page.

The main visual remains the center of attention, while text, navigation, and background elements support it through a clear visual hierarchy.
